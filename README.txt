Arquivo: index.html
Objetivo: página simples que exibe sua página do Google Sites dentro de um iframe e faz auto-refresh a cada 60 segundos.

Como usar:
1) Descompacte o arquivo hosta_refresh.zip.
2) Edite index.html se quiser mudar o tempo de refresh (meta tag content="60") ou a URL do iframe.
3) Suba os arquivos para um host estático (GitHub Pages, Netlify, Vercel, ou seu servidor).

Observações importantes:
- O arquivo aponta para: https://sites.google.com/view/hostainteligente/início
- Caso queira outro caminho, substitua a URL no campo 'src' do iframe.
- Para mudar o tempo de atualização, altere <meta http-equiv="refresh" content="60"> para outro valor em segundos.
